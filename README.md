# Library API

RESTful API для управления библиотечным каталогом, разработанное с использованием FastAPI.

## Функциональность

- Аутентификация пользователей (библиотекарей) с использованием JWT
- Управление книгами (CRUD операции)
- Управление читателями (CRUD операции)
- Выдача и возврат книг
- Отслеживание выданных книг
- Логирование операций
- Обработка ошибок и валидация данных

## Технический стек

- Python 3.8+
- FastAPI
- PostgreSQL
- SQLAlchemy (ORM)
- Alembic для миграций
- JWT для аутентификации
- Pydantic для валидации данных
- Pytest для тестирования
- Logging для логирования

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd library-api
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate     # для Windows
pip install -r requirements.txt
```

3. Создайте файл .env и настройте переменные окружения:
```env
DATABASE_URL=postgresql://postgres:777@localhost:5433/library_db?sslmode=prefer
SECRET_KEY=your-secret-key-here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

4. Создайте базу данных PostgreSQL:
```bash
createdb library_db
```

5. Примените миграции:
```bash
alembic upgrade head
```

6. Запустите приложение:
```bash
uvicorn app.main:app --reload
```

7. Регистрация первого пользователя:
```bash
curl -X POST "http://localhost:8000/auth/register" \
     -H "Content-Type: application/json" \
     -d '{"email": "admin@library.com", "password": "admin123", "is_superuser": true}'
```

## Структура базы данных

### Таблицы и связи

1. **users** - Пользователи системы (библиотекари)
   - id (PK)
   - email (unique)
   - hashed_password
   - is_active
   - is_superuser
   - created_at
   - updated_at

2. **books** - Книги
   - id (PK)
   - title
   - author
   - isbn (unique)
   - description
   - copies_available
   - created_at
   - updated_at

3. **readers** - Читатели
   - id (PK)
   - name
   - email (unique)
   - phone
   - created_at
   - updated_at

4. **borrowed_books** - Выданные книги
   - id (PK)
   - book_id (FK -> books.id)
   - reader_id (FK -> readers.id)
   - borrowed_at
   - returned_at
   - due_date

### Принятые решения

1. **Разделение пользователей и читателей**
   - Пользователи (библиотекари) имеют доступ к системе
   - Читатели - это клиенты библиотеки
   - Разделение позволяет независимо управлять правами доступа

2. **Отслеживание количества книг**
   - Поле copies_available в таблице books
   - Упрощает проверку доступности книг
   - Позволяет эффективно управлять инвентарем

3. **История выдачи книг**
   - Таблица borrowed_books хранит полную историю
   - Поля borrowed_at и returned_at для отслеживания сроков
   - Возможность аналитики по выдаче книг

## Бизнес-логика

### 1. Выдача книг
```python
# Проверки перед выдачей:
- Существование книги и читателя
- Доступность книги (copies_available > 0)
- Отсутствие активной выдачи этой книги читателю
- Количество активных выдач у читателя < 3
```

### 2. Возврат книг
```python
# Проверки перед возвратом:
- Существование записи о выдаче
- Книга не была возвращена ранее
- Обновление количества доступных экземпляров
```

### 3. Управление пользователями
```python
# Особенности реализации:
- Хеширование паролей с помощью bcrypt
- Проверка уникальности email
- Разделение прав доступа (обычный пользователь/суперпользователь)
```

### Сложности и их решения

1. **Проблема**: Конкурентный доступ при выдаче книг
   **Решение**: Использование транзакций в базе данных

2. **Проблема**: Дублирование email при регистрации
   **Решение**: Обработка IntegrityError и преобразование в понятное сообщение об ошибке

3. **Проблема**: Управление состоянием книг
   **Решение**: Атомарные операции обновления copies_available

## Аутентификация

### Реализация

1. **Генерация токенов**
   - Использование библиотеки python-jose
   - Алгоритм HS256
   - Время жизни токена настраивается в .env
   - В токен включается email пользователя

2. **Проверка токенов**
   - Middleware FastAPI для проверки заголовка Authorization
   - Валидация подписи и срока действия
   - Извлечение email пользователя

3. **Защищенные эндпоинты**
   - Все эндпоинты кроме /auth/* требуют токен
   - Проверка прав доступа для определенных операций
   - Защита от неавторизованного доступа

### Использованные библиотеки

1. **python-jose**
   - Надежная реализация JWT
   - Поддержка различных алгоритмов
   - Хорошая документация

2. **passlib**
   - Безопасное хеширование паролей
   - Поддержка bcrypt
   - Простота использования
